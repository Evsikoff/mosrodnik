# Логотип «Московский родник»

Знак объединяет геометрическую букву «М», склоны оврага, точку источника и два кольца на воде.
Из референсов взят принцип плотной геометрии и крупной двухстрочной надписи.
Палитра проекта сохранена: ink `#1F2A3A`, ice `#9FC3D6`, snow `#F3F1EC`; тёмный фон — dusk `#2C3A52`.
Цвет логотипа не является статусом анализа и не обещает питьевое качество воды.

Откройте `../../../preview/logo.html`: там показаны статичные версии, размеры, оба спрайт-шита
и работающая анимация с выключателем. Это локальная страница демонстрации, код приложения не добавлялся.

## Что использовать

| Файл | Назначение |
|---|---|
| `logo.svg` | Основной знак, viewBox 0 0 48 48 |
| `logo-mono.svg` | Одноцветный знак ink |
| `logo-inverse.svg` | Светлый знак snow |
| `logo-lockup.svg` | Знак с надписью «МОСКОВСКИЙ РОДНИК», 384 × 112 |
| `logo-lockup-mono.svg` | Та же композиция, одноцветная ink |
| `logo-lockup-inverse.svg` | Та же композиция, светлая snow |
| `logo-mark-512.png` | Прозрачный знак 512 × 512 |
| `logo-lockup.png` | Прозрачный логотип 1536 × 448 |
| `logo-mark-sprite-{color,mono,inverse}.png` | Три варианта спрайт-шита знака |
| `logo-lockup-sprite-{color,mono,inverse}.png` | Три варианта спрайт-шита полной композиции |
| Те же имена с `.webp` | Спрайт-шиты WebP без потерь, с прозрачностью |
| `logo-sprite.json` | Размеры атласов, координаты всех кадров, частота и длительность |
| `logo-animation.css` | Готовые классы и покадровые keyframes |
| `logo-presentation.png` | Светлая и тёмная версии на одном презентационном листе |

Надпись — Golos Text Bold, переведённый в кривые. Для SVG и спрайтов загружать шрифт не требуется.
Для самой страницы демонстрации используется локальный шрифт с лицензией в `assets-src/fonts/ofl.txt`.
Минимум для отдельного знака — 16 CSS px; для полной композиции — 240 CSS px по ширине.
Охранное поле при размещении — не менее четверти высоты знака с каждой стороны.

## Как устроен спрайт

Оба атласа содержат 24 кадра: 6 столбцов и 4 строки. Порядок — слева направо, затем вниз.
Нумерация — от 0 до 23. Пустых ячеек и дополнительного повторённого конечного кадра нет.

| Вариант | Размер PNG/WebP | Ячейка в файле | Базовый размер в CSS |
|---|---|---|---|
| Знак | 1536 × 1024 px | 256 × 256 px | 128 × 128 px |
| Полная композиция | 4608 × 896 px | 768 × 224 px | 384 × 112 px |

Экспорт выполнен в масштабе 2x относительно базового размера CSS. Фон прозрачный; кадры не обрезаны.
Частота — 12 кадров/с, один цикл — 2 секунды. Кадр 0 совпадает со статичным SVG.
В цикле слегка изменяются ширина и высота колец и прозрачность внешнего кольца.
Буква «М», точка источника и надпись неподвижны. Геометрия вычисляется периодическими функциями,
поэтому переход с кадра 23 на кадр 0 продолжает движение без скачка фазы.

## Подключение через CSS

Пути ниже предполагают, что `web/public` публикуется как корень сайта.
Если файл CSS перенесён, сохраните его рядом с PNG или поправьте относительные пути внутри.

```html
<link rel="stylesheet" href="/brand/logo-animation.css">

<!-- Полный логотип с анимацией. -->
<span class="mr-logo mr-logo--lockup mr-logo--animated"
      role="img" aria-label="Московский родник"></span>

<!-- Только знак, ширина 64 px. -->
<span class="mr-logo mr-logo--animated"
      style="--logo-width: 64px"
      role="img" aria-label="Московский родник"></span>

<!-- Светлый полный логотип на тёмном фоне. -->
<span class="mr-logo mr-logo--lockup mr-logo--inverse mr-logo--animated"
      role="img" aria-label="Московский родник"></span>
```

Без `mr-logo--animated` показывается первый кадр. Размер меняется через `--logo-width`,
а пропорции и координаты кадров сохраняются. Класс `mr-logo--mono` выбирает одноцветный вариант.
`background-size: 600% 400%` соответствует шести столбцам и четырём строкам.
Движение отключается при `prefers-reduced-motion: reduce` — в CSS это уже предусмотрено.
Для статичного логотипа обычно проще использовать `<img src="/brand/logo-lockup.svg" ...>`.

При размещении внутри ссылки на главную имя доступно на самой ссылке, а картинка скрыта от повторного чтения:

```html
<a class="brand-link" href="/" aria-label="Московский родник — главная">
  <span class="mr-logo mr-logo--lockup" aria-hidden="true"></span>
</a>
```

Чтобы анимировать только при наведении и фокусе с клавиатуры, добавьте после основного CSS:

```css
@media (prefers-reduced-motion: no-preference) {
  .brand-link:hover .mr-logo,
  .brand-link:focus-visible .mr-logo {
    animation: mr-logo-ripples 2s steps(1, end) infinite;
  }
}
```

Готовый CSS использует PNG. Чтобы использовать WebP, замените соответствующее `background-image`,
например на `url('/brand/logo-lockup-sprite-color.webp')`; геометрия атласа одинаковая.
Не меняйте двухмерный атлас на простую анимацию `steps(24)` по одной оси:
нужны обе координаты каждого кадра, как в поставляемых keyframes.

## Для Canvas или собственного проигрывателя

Прочитайте `logo-sprite.json`, выберите `sheets['lockup-color']` или `sheets['mark-color']`.
У кадра заданы `x`, `y`, `width`, `height` в физических пикселях файла.
Индекс в момент времени `elapsedMs`: `Math.floor(elapsedMs / (1000 / 12)) % 24`.
Эти четыре координаты передаются в `drawImage` как область источника; размеры назначения
берутся из `display_width`, `display_height` или масштабируются с сохранением пропорций.
При отключённом движении показывайте индекс 0. При уходе вкладки в фон останавливайте проигрыватель.

## Пересборка

Из корня проекта:

```powershell
python assets-src/scripts/build-assets.py
python assets-src/scripts/logo-assets.py
python assets-src/scripts/import-images.py
python assets-src/scripts/build-preview.py
python assets-src/scripts/manifest.py
python assets-src/scripts/check_assets.py
```

`build-assets.py` обновляет знак, фавиконки и PWA-иконки. `logo-assets.py` создаёт надписи,
спрайты, JSON, CSS и демонстрацию. `import-images.py` обновляет OG-изображение с новым знаком
из уже сохранённой иллюстрации, без новой генерации.
Полную сборку всего комплекта запускает `python assets-src/scripts/rebuild.py`.

Геометрия знака и формулы движения находятся в `assets-src/scripts/brandmark.py`.
Размеры кадра, сетка и частота — в `assets-src/scripts/logo-assets.py`.
После их изменения пересоберите JSON и CSS вместе со спрайтами, затем выполните проверку.
Для нового темпа меняйте длительность CSS пропорционально: 3 секунды дадут более медленный цикл.
Масштабирование и анимация самого текста не нужны; избегайте резких вспышек, вращения и бликов.
