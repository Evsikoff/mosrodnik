# Презентация «Московский родник»

Шесть слайдов в формате 16:9. Ориентировочная длительность выступления — 2 минуты 40 секунд.
Слайды показывают работающий прототип и следующий шаг: пилот с жителями и экологами.
Демонстрационные отзывы не выдаются за реальную активность, запланированные возможности не заявлены как готовые.

## Что здесь находится

- `presentation.json`: общий стиль, отдельный промпт каждого слайда, точный текст на экране,
  речь докладчика, имена и пути аудиофайлов, промпт музыки и правила последующей сборки.
- `slides/slide-01.png`…`slide-06.png`: готовые слайды, 1920 × 1080.
- `sources/`: оригинальные изображения, полученные от Gemini.
- `generation.json`: фактические промпты, референсы, модель, время генерации и хеши файлов.
- `references/`: настоящие снимки интерфейса, использованные как референсы.
- `preview.html`: просмотр слайдов с кнопками и стрелками клавиатуры, без автоматического воспроизведения.
- `outputs/moskovsky-rodnik.pptx`: слайды-картинки в PowerPoint, тексты докладчика в заметках.
- `contact-sheet.jpg`: все шесть слайдов на одном листе.
- `speaker-notes.txt`: тексты озвучки отдельно от JSON.
- `music-prompt.txt`: промпт фоновой музыки на английском и русском.

## Куда положить звук

Сохраните шесть отдельных WAV в `audio/voiceover/`:

```text
slide-01.wav
slide-02.wav
slide-03.wav
slide-04.wav
slide-05.wav
slide-06.wav
```

Фоновая музыка: `audio/music/background.wav`.
Не встраивайте её в файлы голоса. Подробные инструкции находятся в README этих папок.
Точная длительность слайдов будет зависеть от полученной озвучки. Сейчас голоса, музыки и видеомонтажа нет.
После добавления аудио сообщите, что делать дальше.

## Генерация

Слайды созданы через Gemini 3 Pro Image (Nano Banana Pro), а не нарисованы программно.
В PowerPoint они остаются растровыми изображениями. Для изменения текста сохранены исходные промпты.
Ключ читается только локальным инструментом из `.env.local`, переменная `GEMINI_API_KEY`.

```powershell
node presentations/moskovsky-rodnik/scripts/generate-slides.mjs
node presentations/moskovsky-rodnik/scripts/finalize-slide-images.mjs
node presentations/moskovsky-rodnik/scripts/build-preview.mjs
```

Уже сохранённые изображения повторно не запрашиваются. Для отдельных ещё не созданных слайдов
можно передать `--only=2,3`. Публичные ассеты приложения и база отзывов не изменяются.
