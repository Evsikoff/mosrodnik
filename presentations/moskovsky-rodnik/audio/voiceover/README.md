# Озвучка слайдов

Положите сюда шесть файлов: `slide-01.wav`, `slide-02.wav`, `slide-03.wav`, `slide-04.wav`,
`slide-05.wav`, `slide-06.wav`.

Тексты находятся в `../../presentation.json`, поле `slides[].speaker_text`.
Записывайте только этот текст, без названия слайда и служебных инструкций.
Используйте один голос, спокойный темп и одинаковую громкость. Не добавляйте музыку в эти файлы.
Желательно WAV PCM 16-bit, 48 кГц, моно. Если сервис выдаёт другой WAV, сохраните его как есть.

Итоговую длительность слайдов определим по полученным записям. Пока озвучка не создавалась.
