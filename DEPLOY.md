# Деплой на Northflank

Приложение собирается одним `Dockerfile` и работает одним процессом: API, статика и SPA-маршруты (`/spring/*`).

## Текущий стенд

- Репозиторий: https://github.com/Evsikoff/mosrodnik, ветка `main`. Каждый пуш в `main` пересобирает сервис.
- Northflank: команда `evsikoffs-team`, проект `mosrodnik`, регион `europe-west`, сервис `mosrodnik`
  (combined, сборка `nf-compute-400-16`, запуск `nf-compute-50`, 1 экземпляр).
- Том `mosrodnik-data` (nvme, 6 ГБ, меньше этот класс не бывает) смонтирован в `/data`.
- Адрес: https://http--mosrodnik--cl5z8kwqkn5c.code.run
- Переменные заданы по таблице из раздела 4, секреты сгенерированы случайно и хранятся только в Northflank.
  Стенд демонстрационный, поэтому `SAMPLES_AFFECT_MAP=1`: образцы влияют на маркеры и фильтры, как локально.

Ниже шаги для повторной настройки с нуля.

## 1. Репозиторий

1. Создайте приватный репозиторий на GitHub и запушьте проект. Проверьте, что `.env.local` не попал в коммит:
   ```bash
   git ls-files | grep -i "\.env"
   ```
   Команда должна вывести только `.env.example`.
2. Секреты нужны только в Northflank, в репозиторий их класть не надо.

## 2. Сервис

1. В Northflank: **Create new, Service, Combined service** (сборка и запуск).
2. Источник: ваш репозиторий GitHub, ветка `main`.
3. Сборка: **Dockerfile**, путь `/Dockerfile`, контекст `/`.
4. Порт: добавьте порт `3000`, протокол **HTTP**, включите **Publicly expose**. Платформа задаёт `PORT` сама;
   если задаёте вручную, укажите `3000`.
5. Health check: **HTTP**, путь `/api/health`, порт `3000`.

## 3. Постоянный том

Файловая система контейнера временная, а JSON-база и загруженные фото живут в `DATA_DIR`.

1. В сервисе: **Volumes, Add volume**, размер от 1 ГБ (для класса nvme Northflank требует минимум 6 ГБ).
2. Точка монтирования: `/data`.
3. Переменная `DATA_DIR=/data` (она уже задана в образе, но лучше указать явно).
4. При первом старте на пустом томе сервер сам копирует образцы и опорный `springs.geojson` из образа и
   заполняет `springs/`. Дальше родники обновляет синхронизация.

Том подключается к одному экземпляру: не ставьте больше одной реплики.

## 4. Переменные окружения

В **Environment, Runtime variables** добавьте (шаблон: `.env.example`):

| Переменная | Значение |
|---|---|
| `DATAMOS_API_KEY` | ключ API data.mos.ru (пометьте как секрет) |
| `DATA_DIR` | `/data` |
| `SESSION_SECRET` | длинная случайная строка, например результат `openssl rand -hex 32` |
| `SESSION_SALT` | другая длинная случайная строка. После запуска менять нельзя: перестанут узнаваться устройства |
| `ADMIN_TOKEN` | длинная случайная строка для скрытия записей модератором |
| `PUBLIC_URL` | публичный адрес сервиса, например `https://mosrodn--xxxx.code.run` |
| `SAMPLES_AFFECT_MAP` | `1` для демонстрационного стенда; без переменной в продакшене образцы не влияют на карту |

`DATAMOS_API_KEY` не попадает в образ: `.env*` исключены через `.dockerignore`, значение передаётся только как
переменная окружения во время работы.

## 5. Проверка

1. Откройте публичный адрес: должна загрузиться карта с 258 родниками.
2. `https://<адрес>/api/health` отвечает `{"status":"ok", ...}`. Поле `last_sync_at` заполнится после первой
   удачной синхронизации; если там `null`, смотрите `last_sync_error`. Приложение при этом работает на последнем
   снимке.
3. Откройте `/spring/zao-8`: карточка должна открыться сразу после загрузки.
4. Оставьте отметку и перезапустите сервис: отметка должна сохраниться (проверка тома).

## 6. Модерация

Скрыть запись (отметку или фото) без удаления:

```bash
curl -X POST https://<адрес>/api/admin/hide \
  -H "X-Admin-Token: $ADMIN_TOKEN" -H "Content-Type: application/json" \
  -d '{"entity":"observations","id":"<id записи>","reason":"спам"}'
```

`entity` бывает `observations` или `photos`. Чтобы вернуть запись, добавьте `"hidden": false`.

## 7. Для Департамента

`GET /api/export/springs.geojson` отдаёт родники с агрегатами по отметкам жителей (без образцов), а
`GET /api/stats` счётчики пользователей, отметок и фото.

## Локальная проверка образа

```bash
docker build -t mosrodn .
docker run --rm -p 3000:3000 -v mosrodn-data:/data -e SESSION_SECRET=test -e SESSION_SALT=test -e ADMIN_TOKEN=test mosrodn
```

## Образцы перед запуском

В продакшене образцы не влияют на карту и фильтры (флаг `SAMPLES_AFFECT_MAP` выключен автоматически). Они
остаются в ленте карточек с плашкой «Образец» до 3 реальных записей у родника. Чтобы убрать их совсем, удалите
файлы `sample*.json` из `data/users`, `data/observations`, `data/photos` перед сборкой образа, а на уже
работающем томе удалите те же файлы в `/data` и перезапустите сервис.
