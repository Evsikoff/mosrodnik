# Московский родник

Веб-приложение о состоянии родников Москвы поверх открытого набора data.mos.ru № 2454.
Полное ТЗ — в `SPEC.md`. Прочитай его перед любой задачей в этом репозитории.

## Правила проекта

- Срок: рабочая версия по публичной ссылке к вечеру 30 октября 2026. Сначала P0 из `SPEC.md`, потом эффекты.
- Никаких эмодзи в интерфейсе, коде разметки, данных и документации.
- Ассеты в `web/public/` готовы — не перерисовывать и не перегенерировать. Опись — `ASSETS.md`.
- Цвета — только из `design/tokens.css`.
- `.env.local` содержит `DATAMOS_API_KEY`. Никогда не коммитить, не копировать в Docker-образ, не выводить в логи.
- JSON-база: папка = сущность, файл = экземпляр. Запись только атомарная.
- Образцы (`is_sample: true`) не влияют на карту, фильтры, статистику и экспорт.
- В карточке родника всегда показывается: анализ только химический, микробиология не проверяется,
  воду из родников рекомендуется пить только после кипячения. Интерфейс не должен обещать «чистую воду».
- Готовые открытые решения предпочтительнее своих (лицензии MIT/BSD/ISC/Apache-2.0/OFL).
- Спорные технические решения записывай в `DECISIONS.md`.
