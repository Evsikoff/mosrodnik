# Московский родник

Веб-приложение о состоянии родников Москвы поверх открытого набора data.mos.ru № 2454.
Полное ТЗ: `SPEC.md`. Решения по ходу работы: `DECISIONS.md`. Деплой: `DEPLOY.md`.

```bash
npm install
npm run dev     # сервер на :3000 и фронтенд на :5173 (ключ из .env.local, если он есть)
npm test        # тесты сервера
npm run demo:seed # обновить демонстрационные отметки и их даты
npm run lint    # проверка эмодзи и типов
npm run build   # сборка web/dist и server/dist
npm start       # продакшен-запуск одним процессом
```

Демонстрационные отметки подписаны «Образец». Генератор создаёт 24 автора и 2 575 дополнительных
наблюдений для 250 родников: течение, подход, чистота, посещения и подтверждение точки.
Повторный запуск обновляет те же записи; реальные сообщения не перезаписываются.
После генерации перезапустите сервер: база загружается в память при старте.
Для повторения набора с фиксированным временем: `npm run demo:seed -- --at=2026-10-29T12:00:00Z`.

К отзывам добавлены 24 синтетических фото Gemini для 22 родников из всех 12 округов.
Исходники и полные промпты перечислены в `assets-src/processing/gemini-review-photos.json`;
контактный лист — `assets-src/qa/review-photos-contact.jpg`. Публичные фото имеют водяные знаки
«ОБРАЗЕЦ», отдельные превью и подписи о синтетическом происхождении.
`demo:seed` сохраняет прикреплённые фото при обновлении отметок.

Повторяемые инструменты подготовки фото:

```bash
node server/scripts/generate-review-photos.mjs --plan # подготовить связи без обращения к API
node server/scripts/generate-review-photos.mjs        # Gemini API; ключ GEMINI_API_KEY из .env.local
python assets-src/scripts/publish-review-photos.py    # водяные знаки, превью и прикрепление к образцам
python assets-src/scripts/publish-review-photos.py --check # проверка без новых запросов к Gemini
```

Сохранённые генерации повторно не запрашиваются. После публикации фото перезапустите сервер.

## Презентация проекта

Материалы для выступления находятся в `presentations/moskovsky-rodnik/`: шесть готовых слайдов,
PowerPoint и `presentation.json` с промптами, текстами докладчика и именами аудиофайлов.
Озвучку `slide-01.wav`…`slide-06.wav` нужно положить в `audio/voiceover/` внутри этой папки,
музыку `background.wav` — в `audio/music/`. Пока звук и видеомонтаж не создавались.
